# คู่มือแฟ้มบริษัท — JuraTools Corporate Dossier

**A guide for an AI asked to turn unstructured client material into a JuraTools
corporate dossier file.**

เอกสารนี้คือแบบของไฟล์ `.dossier.json` ที่เครื่องมือหุ้นทั้งสามตัวของ JuraTools
อ่านและเขียน — ใบหุ้น (Share Certificates), สมุดทะเบียนผู้ถือหุ้น (Share Register
Book) และตราสารการโอนหุ้น (Share Transfer Instrument) หนึ่งไฟล์ = หนึ่งบริษัท

ให้ไฟล์นี้กับ AI พร้อมกับข้อมูลดิบของลูกความ (อีเมล บอจ.5 หนังสือรับรอง สำเนาบัตร
บันทึกการประชุม) แล้วนำไฟล์ที่ได้กลับเข้าเครื่องมือ

---

## 1. สิ่งที่ต้องส่งกลับ

**ส่งกลับเป็น JSON หนึ่งอ็อบเจ็กต์เท่านั้น** — ไม่มีคำอธิบาย ไม่มีข้อความนำ ไม่มี
code fence ไม่มีคอมเมนต์ใน JSON บันทึกเป็นไฟล์ชื่อ `<ชื่อย่อบริษัท>.dossier.json`

ถ้าจะถามหรือจะอธิบาย ให้พูดแยกออกมาต่างหาก **นอกไฟล์**

---

## 2. โครงของไฟล์

ทุกคีย์เป็นตัวเลือก ยกเว้น `format` และ `v` — ส่งเฉพาะส่วนที่มีข้อมูลจริง
ส่วนที่ไม่รู้ให้ **ตัดคีย์นั้นทิ้งไปเลย** ดีกว่าส่งค่าว่างหรือค่าที่เดาเอา

```jsonc
{
  "format": "juratools-corporate-dossier",   // ต้องเป็นค่านี้ตรงตัว
  "v": 1,
  "at": "2026-08-11T09:00:00.000Z",          // เวลาที่สร้างไฟล์ (ISO)
  "from": "ChatGPT / Claude / ชื่อผู้จัดทำ",

  "co": {
    "nameTh":    "บริษัท ตัวอย่าง จำกัด",
    "nameEn":    "EXAMPLE COMPANY LIMITED",
    "regNo":     "0105551000001",            // เลขทะเบียนนิติบุคคล 13 หลัก
    "par":       "100",                      // มูลค่าหุ้นละ (บาท)
    "regShares": "10000",                    // จำนวนหุ้นจดทะเบียนทั้งหมด
    "ord":       "10000",                    // หุ้นสามัญ
    "pref":      "-",                        // หุ้นบุริมสิทธิ ("-" ถ้าไม่มี)
    "cap":       "1000000",                  // ทุนจดทะเบียน (บาท)
    "dirL":      "นายสมชาย ใจดี",             // กรรมการผู้ลงนาม ช่องซ้าย
    "dirR":      "นางสาวมาลี รักไทย"          // กรรมการผู้ลงนาม ช่องขวา
  },

  "people": [
    {
      "nameTh":  "นายสมชาย ใจดี",
      "nameEn":  "MR. SOMCHAI JAIDEE",
      "addrTh":  "99/1 ถนนสุขุมวิท แขวงคลองเตย เขตคลองเตย กรุงเทพมหานคร 10110",
      "addrEn":  "99/1 Sukhumvit Road, Khlong Toei, Bangkok 10110",
      "idType":  "id",                       // id | passport | juristic | both
      "idNo":    "1-2345-67890-12-3",
      "occTh":   "ทนายความ",
      "occEn":   "Lawyer",
      "natTh":   "ไทย",
      "natEn":   "Thai"
    }
  ],

  "register": {
    "holders": [
      {
        "nameTh": "นายสมชาย ใจดี",
        "nameEn": "MR. SOMCHAI JAIDEE",
        "idType": "id",
        "idNo":   "1-2345-67890-12-3",
        "occTh":  "ทนายความ",  "occEn": "Lawyer",
        "natTh":  "ไทย",      "natEn": "Thai",
        "addrTh": "99/1 ถนนสุขุมวิท …", "addrEn": "99/1 Sukhumvit Road …",
        "entries": [
          {
            "kind":    "in",                 // in | out | both | note
            "date":    "2011-01-14",
            "refCert": "-",                  // อ้างถึงใบหุ้นเดิม; "-" ถ้าเป็นการออกครั้งแรก
            "certNo":  "1",
            "shares":  "11800",
            "shareFrom": "1"                 // หุ้นหมายเลขเริ่มต้น — ที่เหลือคำนวณเอง
          },
          {
            "kind":      "out",
            "date":      "2019-03-02",
            "counterTh": "นางสาวมาลี รักไทย",
            "counterEn": "MISS MALEE RAKTHAI",
            "refCert":   "1",
            "outCert":   "8",                // ใบหุ้นที่ออกให้ "ผู้รับโอน" ไม่ใช่ใบที่คืนมา
            "outShares": "8000"
          },
          { "kind": "note", "date": "2020-06-01",
            "descTh": "ไม่ได้เป็นผู้ถือหุ้นของบริษัทอีกต่อไป",
            "descEn": "No longer holds shares in the Company" }

      }

  },

  "certs": [
    {
      "no":       "1",
      "type":     "ordinary",                // ordinary | preference
      "holderTh": "นายสมชาย ใจดี",

      "addrTh":   "99/1 ถนนสุขุมวิท …",

      "paid":     "100"                      // ชำระแล้วหุ้นละ
    }
  ],

  "transfers": [
    {
      "date":      "2019-03-02",
      "tfrTh":     "นายสมชาย ใจดี",           // ผู้โอน
      "tfrEn":     "MR. SOMCHAI JAIDEE",
      "tfeTh":     "นางสาวมาลี รักไทย",        // ผู้รับโอน

  ]

```

## 3. ข้อตกลงเรื่องรูปแบบค่า

นี่คือส่วนที่ผิดกันบ่อยที่สุด

| เรื่อง | กติกา |
|---|---|
| **วันที่** | ISO `YYYY-MM-DD` และเป็น **ค.ศ.** เสมอ ในไฟล์ — เครื่องมือแปลงเป็น พ.ศ. ให้เอง ถ้าต้นทางเขียน `14/01/2554` ให้แปลงเป็น `2011-01-14` |
| **ตัวเลข** | ตัวเลขล้วน ไม่มีจุลภาค ไม่มีสัญลักษณ์เงิน ไม่มีหน่วย → `11800` ไม่ใช่ `"11,800 หุ้น"` |
| **ชื่ออังกฤษ** | ตัวพิมพ์ใหญ่ทั้งหมด พร้อมคำนำหน้า → `MR. SOMCHAI JAIDEE` |
| **ชื่อไทย** | ติดคำนำหน้าไว้กับชื่อ → `นายสมชาย ใจดี` ไม่ต้องแยกฟิลด์ |
| **ไทยกับอังกฤษ** | คนละฟิลด์ ถ้าต้นทางมีแต่ภาษาเดียว **ให้เว้นอีกฟิลด์ว่าง** อย่าถอดเสียงเอง |
| **`idType`** | หนึ่งใน `id` (บัตรประชาชน) · `passport` · `juristic` (นิติบุคคล) · `both` |
| **ที่ยังไม่รู้** | ใส่ `"(*)"` — เครื่องมือจะไฮไลต์สีเหลืองให้ทนายเติมเอง **ห้ามเดา และห้ามเว้นว่างจนดูเหมือนศูนย์** |
| **ที่ไม่มีจริง ๆ** | ใช้ `"-"` เช่น หุ้นบุริมสิทธิที่บริษัทไม่มี |

`(*)` กับ `-` ไม่เหมือนกัน: `(*)` แปลว่า *ยังไม่รู้* · `-` แปลว่า *ไม่มี*

## 4. ตัวอย่างจริง

**ข้อมูลดิบที่ลูกความส่งมา**

> เรียนทนาย
> บริษัทตัวอย่างจำกัด ทะเบียน 0105551000001 ทุน 1 ล้าน แบ่งเป็น 10,000 หุ้น
> หุ้นละ 100 บาท ตอนตั้งบริษัทปี 54 คุณสมชาย ใจดี (บัตร 1-2345-67890-12-3,
> ทนายความ, อยู่ 99/1 ถ.สุขุมวิท คลองเตย กทม. 10110) ถือ 11,800 หุ้น ใบหุ้นเลข 1
> ต่อมา 2 มีค 62 โอนให้คุณมาลี รักไทย 8,000 หุ้น ออกใบหุ้นเลข 8 ให้คุณมาลี
> ไม่แน่ใจว่าคุณมาลีสัญชาติอะไร

**ไฟล์ที่ควรส่งกลับ**

```json
{
  "format": "juratools-corporate-dossier",
  "v": 1,
  "at": "2026-08-11T09:00:00.000Z",
  "from": "Claude",
  "co": {
    "nameTh": "บริษัท ตัวอย่าง จำกัด",
    "nameEn": "(*)",
    "regNo": "0105551000001",
    "par": "100",
    "regShares": "10000",
    "cap": "1000000"
  },
  "people": [
    { "nameTh": "นายสมชาย ใจดี", "nameEn": "(*)",
      "addrTh": "99/1 ถนนสุขุมวิท เขตคลองเตย กรุงเทพมหานคร 10110", "addrEn": "(*)",
      "idType": "id", "idNo": "1-2345-67890-12-3",
      "occTh": "ทนายความ", "occEn": "(*)", "natTh": "ไทย", "natEn": "Thai" },
    { "nameTh": "นางสาวมาลี รักไทย", "nameEn": "(*)",
      "idType": "(*)", "idNo": "(*)", "natTh": "(*)", "natEn": "(*)" }
  ],
  "register": {
    "holders": [
      { "nameTh": "นายสมชาย ใจดี",
        "idType": "id", "idNo": "1-2345-67890-12-3",
        "occTh": "ทนายความ", "natTh": "ไทย",
        "addrTh": "99/1 ถนนสุขุมวิท เขตคลองเตย กรุงเทพมหานคร 10110",
        "entries": [
          { "kind": "in", "date": "2011-01-14", "refCert": "-",
            "certNo": "1", "shares": "11800", "shareFrom": "1" },
          { "kind": "out", "date": "2019-03-02",
            "counterTh": "นางสาวมาลี รักไทย",
            "refCert": "1", "outCert": "8", "outShares": "8000" }
        ] },
      { "nameTh": "นางสาวมาลี รักไทย",
        "entries": [
          { "kind": "in", "date": "2019-03-02",

    "ไม่มีชื่อภาษาอังกฤษของบริษัทและของบุคคลในเอกสารต้นทาง"
```

หน้าผู้รับโอน

## 5. กฎสองข้อที่ห้ามฝ่าฝืน

1. **ห้ามคิดเลขใบหุ้นหรือหุ้นหมายเลขขึ้นเอง** เครื่องมือคำนวณให้ ถ้าต้นทางไม่ได้
   บอกเลขใบหุ้น ให้ตัดคีย์นั้นทิ้ง อย่าไล่เลข 1, 2, 3 ให้เอง
2. **ถ้าต้นทางขัดกันเอง ให้ใส่ทั้งสองทางแล้วบอกไว้ใน `notes`** อย่าเลือกข้างเอง
   เช่น บอจ.5 กับสมุดทะเบียนไม่ตรงกัน ให้บันทึกไว้ว่าไม่ตรงกันอย่างไร ทนายเป็นคน
   ตัดสิน ไม่ใช่ AI

## 6. คำสั่งสำเร็จรูป

วางข้อความนี้ไว้ต้นบทสนทนา พร้อมแนบคู่มือฉบับนี้และข้อมูลดิบ

> ช่วยอ่านข้อมูลบริษัทที่แนบมา แล้วสร้างไฟล์ JuraTools corporate dossier ตามคู่มือ
> ที่แนบมาด้วย
>
> - ตอบกลับเป็น JSON หนึ่งอ็อบเจ็กต์เท่านั้น ไม่ต้องมีคำอธิบายหรือ code fence
> - วันที่เป็น ค.ศ. รูปแบบ YYYY-MM-DD · ตัวเลขไม่มีจุลภาค
> - ชื่ออังกฤษเป็นตัวพิมพ์ใหญ่ · ไทยกับอังกฤษคนละฟิลด์ ไม่ต้องถอดเสียงให้
> - อะไรที่เอกสารไม่ได้บอก ใส่ "(*)" ห้ามเดา
> - ห้ามคิดเลขใบหุ้นหรือหุ้นหมายเลขขึ้นเอง
> - ถ้าข้อมูลขัดกัน ใส่ทั้งสองทางแล้วอธิบายไว้ใน notes
>
> ถ้ามีอะไรที่ต้องถามก่อน ให้ถามมาก่อนสร้างไฟล์

## 7. หมายเหตุสำหรับผู้ดูแลเครื่องมือ

ไฟล์นี้คือ **ต้นฉบับ** ของคู่มือ เครื่องมือทั้งสามฝังข้อความเดียวกันนี้ไว้เป็น
`GUIDE_MD` เพื่อให้ปุ่มดาวน์โหลดทำงานได้โดยไม่ต้องต่อเน็ต (House Style ข้อ 4)
แก้ที่ไฟล์นี้ก่อน แล้วคัดลอกไปวางในบล็อกที่คั่นไว้ในแต่ละเครื่องมือ

เครื่องมือแต่ละตัวเป็นเจ้าของคนละส่วน — ตราสาร → `transfers` · ใบหุ้น → `certs` ·
สมุดทะเบียน → `register` ส่วนที่ไม่ได้เป็นเจ้าของจะถูกเก็บไว้ใน `carry` และเขียน
กลับออกไปเหมือนเดิมทุกตัวอักษร เปิดไฟล์เดียวกันวนครบทั้งสามเครื่องมือแล้วข้อมูล
ต้องไม่หาย
