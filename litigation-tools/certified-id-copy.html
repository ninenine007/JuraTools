Certified ID Copy

สำเนาบัตรประจำตัวประชาชน — รับรองสำเนาถูกต้อง

นำภาพสแกนหรือภาพถ่ายบัตรจริงมาปรับมุมให้ตรงเป็นขนาดจริง 85.6 × 54 มม. (ISO/IEC 7810 ID-1) แล้ววางข้อความ “ใช้สำหรับ … เท่านั้น” ทับบัตร พร้อมช่องรับรองสำเนาถูกต้อง ออกเป็นไฟล์ Word (.docx) ขนาด A4 ที่พิมพ์ได้ขนาดจริง — เครื่องมือนี้ไม่สร้างหรือแก้ไขข้อมูลบนบัตร ใช้กับภาพบัตรจริงเท่านั้น

🔒 ภาพบัตรอยู่ในหน่วยความจำของเบราว์เซอร์นี้เท่านั้น — ไม่อัปโหลด ไม่บันทึกลงเครื่อง ปิดแท็บแล้วหายไป

หน้ากระดาษ

A4 page & print fidelity
ทำไมไฟล์ Word เดิมถึงเพี้ยน และหน้านี้กันไว้อย่างไร
  1. ภาพบัตรไม่ได้สัดส่วน — ภาพที่วางใน Word มักครอบขอบเกินหรือถูกยืดเมื่อลากมุม บัตรจริงคือ 85.6 × 54 มม. (1.586 : 1) ที่นี่ปรับมุม 4 จุด (perspective) แล้ววาดออกมาที่ขนาดนั้นเสมอ
  2. ความละเอียดต่ำ — ภาพจากหน้าเว็บ/แชตมัก 96 dpi พอขยายเป็นขนาดบัตรเหลือราว 150 dpi จึงเบลอ ที่นี่แสดง dpi จริงของภาพและเตือนเมื่อต่ำกว่า 200
  3. กล่องข้อความลอยผูกกับย่อหน้า — ใน Word ตำแหน่งขึ้นกับย่อหน้าและฟอนต์ เปิดเครื่องที่ไม่มี Cordia New ข้อความจะขยายหรือเลื่อน ที่นี่ทุกชิ้นยึดกับหน้ากระดาษเป็นมิลลิเมตร ไม่ยึดกับย่อหน้า และใช้ TH SarabunPSK ซึ่งมีในเครื่องทั่วไป
  4. ขนาดกระดาษ — ไฟล์เดิมตั้งเป็น Letter (8.5 × 11 นิ้ว) พอพิมพ์ลง A4 เครื่องพิมพ์จะย่อให้พอดี บัตรจึงเล็กกว่าจริง ที่นี่ตั้งเป็น A4
  5. ตอนพิมพ์ — ต้องเลือก “ขนาดจริง / Actual size / 100%” ไม่ใช่ “Fit to page”
การตั้งค่ารูปแบบ (มุม ขนาด สี ฟอนต์) จำไว้ในเบราว์เซอร์นี้ — ภาพ ชื่อ และวันที่ไม่ถูกจำ
