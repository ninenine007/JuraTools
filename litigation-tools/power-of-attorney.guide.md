# คู่มือ AI — หนังสือมอบอำนาจให้ฟ้องคดี · v1

**เอกสารนี้เขียนให้ AI อ่าน** เมื่อถูกขอให้ร่างหนังสือมอบอำนาจให้ฟ้องคดีจากข้อเท็จจริงของเรื่อง
(อีเมล สัญญา หนังสือรับรองบริษัท บันทึกข้อเท็จจริง) ใช้ได้สองทาง:

- **MCP** — เรียกเครื่องมือ `create_power_of_attorney` ของ JuraTools MCP server (ได้ไฟล์ `.docx` กลับมา)
- **หน้าเว็บ** — `litigation-tools/power-of-attorney.html` › “เปิดไฟล์งาน / JSON จาก AI” รับ JSON แบบเดียวกับ input ของ MCP

เครื่องมือ **ไม่ร่างหนังสือใหม่** — ใช้แบบของสำนักงาน (ส่วนที่ไฮไลต์เหลืองในไฟล์ต้นแบบ) ทุกตัวอักษร
แล้วพิมพ์เฉพาะส่วนที่เปลี่ยนตามเรื่องลงใน run เดิมของ Word งานของ AI คือ **เขียนส่วนที่เปลี่ยนให้ถูก สั้น และตรงกับเอกสาร**

---

## ๑. ข้อความคงที่ — AI ไม่ต้องเขียนซ้ำ

```
หนังสือมอบอำนาจ
                                   ทำที่ [place]
                          [date]
    โดยหนังสือฉบับนี้ [ข้าพเจ้า] [grantor] (“ผู้มอบอำนาจ”) [capacity] ขอมอบอำนาจให้บุคคลที่มีรายนามดังต่อไปนี้
    ┌ ที่ │ รายนามผู้รับมอบอำนาจ │ เลขที่บัตรประจำตัวประชาชน ┐   ← attorneys
    ซึ่งต่อไปในหนังสือฉบับนี้จะเรียกว่า (“ผู้รับมอบอำนาจ”) โดยให้มีอำนาจร่วมกัน และ/หรือ แยกกันกระทำการแทน
    และในนามและเพื่อประโยชน์ของผู้มอบอำนาจ ในการฟ้องร้องดำเนินคดีทั้งทางแพ่งและอาญา ตลอดจนดำเนินการ
    ทางกฎหมายใด ๆ ที่เกี่ยวข้องกับ[counterparty] (“คู่กรณี”) [narrative] (“[definedTerm]”)
    ทั้งนี้ ให้ผู้รับมอบอำนาจมีอำนาจรวมถึงแต่ไม่จำกัดเพียงการดำเนินการดังต่อไปนี้ด้วย
      1. …ยื่นฟ้องและดำเนินคดีแพ่งและอาญากับคู่กรณีต่อศาล[courts] หรือศาลสถิตยุติธรรมอื่นใด… ในผลเสียหายจาก[definedTerm]ของคู่กรณี…
      2. เข้าร่วมและดำเนินกระบวนพิจารณา … จำหน่ายสิทธิ … บังคับคดี
      3. แต่งตั้งทนายความ (ป.วิ.พ. มาตรา 62) …
      4. ทำ ลงนาม รับรองคำแปลภาษาไทย …
      5. เจรจา ไกล่เกลี่ย ประนีประนอมยอมความ …
      6. ให้การ เป็นพยาน … ที่เกี่ยวกับ[definedTerm] ทั้งคดีอาญา …
      7. กระทำการในเรื่องใดๆ ที่จำเป็นหรือเหมาะสม …
      8. แต่งตั้งผู้รับมอบอำนาจช่วง …
    การมอบอำนาจตามหนังสือมอบอำนาจฉบับนี้ ให้มีผลตั้งแต่วันที่ … ผู้มอบอำนาจขอให้สัตยาบัน … ต่อหน้าพยาน …
    [ตารางลงนาม]                    -ติดอากรแสตมป์ [N] บาท-
```

`[narrative]` ถ้าไม่ส่งมา เครื่องมือประกอบให้เป็น
`ต่อ[courts otherBodies] หรือศาลสถิตยุติธรรมที่มีเขตอำนาจ องค์กร หน่วยงานของรัฐ และ/หรือ พนักงานเจ้าหน้าที่ตลอดจนบุคคลที่เกี่ยวข้องอื่นใด อันเนื่องมาจาก[cause]`
— รูปแบบเดียวกับไฟล์ต้นแบบ (สะกด “องค์กร” ให้ถูก)

## ๒. สิ่งที่ AI ต้องหามาใส่

| key | คืออะไร | วิธีเขียน |
|---|---|---|
| `grantor.type` | `"company"` หรือ `"individual"` | |
| `grantor.company.name` | ชื่อนิติบุคคลตามหนังสือรับรอง | “บริษัท … จำกัด” พิมพ์ตัวหนา |
| `grantor.company.registrationNumber` | ทะเบียนนิติบุคคลเลขที่ | 13 หลัก |
| `grantor.company.headOfficeAddress` | สำนักงานแห่งใหญ่ | ตั้งแต่เลขที่ไป (เครื่องมือเติม “สำนักงานแห่งใหญ่ตั้งอยู่ ณ เลขที่”) |
| `grantor.company.directors` | กรรมการผู้ลงนาม | ตามอำนาจกรรมการในหนังสือรับรอง — ถ้าต้องลงนามร่วมกันสองคน ส่งสองคน และส่ง `authorityWording` ตามหนังสือรับรอง |
| `grantor.persons` | บุคคลธรรมดาผู้มอบ (หลายคนได้) | ชื่อพร้อมคำนำหน้า เลขบัตร/หนังสือเดินทาง ภูมิลำเนา |
| `grantor.capacity` | ฐานะ (ถ้ามี) | เช่น “ในฐานะส่วนตัว และในฐานะผู้แทนโดยชอบธรรมของ…” |
| `attorneys` | ผู้รับมอบอำนาจ ตามลำดับในตาราง | ชื่อ + เลขบัตร 13 หลัก (ตรวจหลักสุดท้ายให้) |
| `matterFacts.counterparty` | คู่กรณีที่จะฟ้อง | ตามชื่อในสัญญา/เอกสาร หลายรายคั่นด้วย “ และ/หรือ ” |
| `matterFacts.courts` | ศาลที่จะฟ้อง | ขึ้นต้นด้วย “ศาล” ทุกรายการ เช่น `["ศาลแพ่ง", "ศาลอาญา"]` |
| `matterFacts.otherBodies` | หน่วยงานอื่นที่จะร้องเรียนด้วย | เช่น `["แพทยสภา"]` — แล้วเพิ่มข้ออำนาจใน `extraClauses` |
| `matterFacts.cause` | เหตุ (ต่อจาก “อันเนื่องมาจาก”) | นิติสัมพันธ์ + เอกสาร + วันที่ + การผิดสัญญา/ละเมิด ไม่มีจุดท้าย |
| `matterFacts.definedTerm` | ชื่อเรียกเหตุ | สั้น ไม่มีเครื่องหมายคำพูด เช่น “การผิดสัญญา”, “การทำละเมิด”, “การผิดนัดชำระหนี้” |
| `extraClauses` | ข้ออำนาจที่ ๘ ข้อคงที่ไม่ครอบคลุม | `{ "afterClause": 0–8, "text": "ให้มีอำนาจ…" }` ลำดับเลขข้อเรียงให้เอง |
| `witnesses` | พยาน | `""` = เว้นเส้นให้เขียนเอง ค่าตั้งต้นพยานว่างสองคน |
| `place`, `date` | ทำที่ · วันที่ | ไม่รู้ให้เว้น (ไม่ส่ง) — **ห้ามเดา** |

**ห้ามแต่งข้อมูล** ชื่อ เลขบัตร เลขทะเบียน วันที่ จำนวนเงิน ที่ไม่มีในเอกสาร — ไม่รู้ให้ละ key หรือใส่ `"(*)"`
(พิมพ์ออกมาเป็นไฮไลต์เหลือง ให้ทนายเติมก่อนลงนาม)

## ๓. ตัวอย่าง (สมมุติ)

```json
{
  "matter": "บริษัท ตัวอย่างการค้า - [คดีบริษัท ทดลอง]",
  "place": "เลขที่ 99 ถนนสมมุติ แขวงตัวอย่าง เขตทดลอง กรุงเทพมหานคร 10000",
  "date": "2026-10-01",
  "grantor": { "type": "company", "company": {
    "name": "บริษัท ตัวอย่างการค้า จำกัด", "registrationNumber": "0105500000000",
    "headOfficeAddress": "99 ถนนสมมุติ แขวงตัวอย่าง เขตทดลอง กรุงเทพมหานคร",
    "directors": [{ "name": "นายสมมุติ ผู้บริหาร" }] } },
  "attorneys": [{ "name": "นายทนาย หนึ่ง", "idNumber": "(*)" }, { "name": "นางสาวทนาย สอง", "idNumber": "(*)" }],
  "matterFacts": {
    "counterparty": "บริษัท ทดลองพัฒนา จำกัด",
    "courts": ["ศาลแพ่ง"],
    "cause": "นิติสัมพันธ์ตามสัญญาซื้อขายสินค้า ระหว่างผู้มอบอำนาจและคู่กรณี ลงวันที่ 1 มีนาคม 2569 หากแต่คู่กรณีผิดสัญญาไม่ชำระราคาสินค้าดังกล่าว",
    "definedTerm": "การผิดสัญญา"
  }
}
```

รูปแบบการบรรยายที่ใช้ในแบบของสำนักงาน:

| เรื่อง | cause | definedTerm |
|---|---|---|
| ผิดสัญญา | นิติสัมพันธ์ตามสัญญา… ลงวันที่ … หากแต่คู่กรณีผิดสัญญา… | การผิดสัญญา |
| ละเมิด | การที่คู่กรณี… จนเป็นเหตุให้ผู้มอบอำนาจได้รับความเสียหาย ซึ่งถือเป็นการทำละเมิดต่อผู้มอบอำนาจ | การทำละเมิด |
| หนี้ค่าสินค้า | การที่คู่กรณีผิดนัดไม่ชำระราคาสินค้าตามใบสั่งซื้อเลขที่ … รวมเป็นเงินทั้งสิ้น … บาท (…) | การผิดนัดชำระหนี้ |
| ละเมิด + ร้องเรียนหน่วยงาน | (ตามละเมิด) + `otherBodies` + ข้อเพิ่ม “ให้มีอำนาจในการยื่นคำร้อง คำขอ ข้อร้องเรียน … ต่อ[หน่วยงาน]…” (`afterClause: 3`) | การทำละเมิด |

## ๔. อากรแสตมป์ — เครื่องมือคำนวณให้

บัญชีอัตราอากรแสตมป์ ลักษณะ ๗ ใบมอบอำนาจ:
**(ข)** ผู้รับมอบคนเดียว (หรือหลายคนร่วมกัน) กระทำการมากกว่าครั้งเดียว ๓๐ บาท ·
**(ค)** หลายคนต่างคนต่างกระทำการได้ **คนละ ๓๐ บาท** — ถ้อยคำ “ร่วมกัน และ/หรือ แยกกัน” ของแบบนี้ต้องเสียตาม (ค)
(ฎ.7275/2543, ฎ.4932/2549) ปิดไม่ครบ ใช้เป็นพยานหลักฐานไม่ได้ (ม.118) และผู้รับมอบอำนาจไม่มีอำนาจฟ้องแทน (ฎ.10222/2558)

ผู้มอบหลายคนที่มิได้เป็นผู้มีอำนาจร่วมกัน คิดแยกตามรายผู้มอบ (หมายเหตุท้ายลักษณะ ๗, ม.108) — ค่าตั้งต้นนับบุคคลธรรมดาแต่ละคนแยกกัน
ถ้าทนายเห็นว่าเป็นผู้มีสิทธิร่วมกันให้ส่ง `stampDuty.principals: 1` บริษัทนับหนึ่งรายเสมอ

## ๕. สิ่งที่ต้องบอกผู้ใช้หลังสร้างไฟล์

- ช่องที่ว่าง (`blankFields`) และเลขบัตรที่ไม่ผ่านหลักตรวจ (`invalidIdNumbers`)
- อากรแสตมป์ที่พิมพ์ในเอกสาร และฐานการคำนวณ
- **เป็นร่าง** — ทนายต้องตรวจกับเอกสารจริงก่อนลงนาม

## ๖. ประเภทอื่นของหนังสือมอบอำนาจ (ยังไม่เปิด)

มอบอำนาจช่วง · แจ้งความร้องทุกข์ · ขอเอกสาร/พยานหลักฐาน — ใช้แบบต่างจากฉบับนี้ (ข้ออำนาจและถ้อยคำเปิดต่างกัน)
อย่าใช้เครื่องมือนี้ร่างแทน จนกว่าจะเพิ่มแบบของประเภทนั้นเข้าไป
