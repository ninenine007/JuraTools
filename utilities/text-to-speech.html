Text to Speech

แปลงข้อความเป็นเสียงพูด

Paste or type text, pick a voice, and get back a downloadable speech file — powered by Azure AI Speech neural voices in Thai, English, and 140+ other languages.

⚠️
The one exception to "nothing leaves the machine": this tool needs a real text-to-speech engine, so it calls the Azure AI Speech REST API directly from your browser using an API key you supply. Your text and key are sent only to Microsoft Azure — never to any other server, and never stored anywhere but this browser (and only if you choose to remember them).
