# คู่มือ AI — หนังสือมอบอำนาจให้ฟ้องคดี · v2 (ต.ค. 2569)

**เอกสารนี้เขียนให้ AI อ่าน** เมื่อถูกขอให้ร่างหนังสือมอบอำนาจให้ฟ้องคดีจากข้อเท็จจริงของเรื่อง
(อีเมล สัญญา หนังสือรับรองบริษัท บันทึกข้อเท็จจริง) ใช้ได้สองทาง:

- **MCP** — เรียกเครื่องมือ `create_power_of_attorney` ของ JuraTools MCP server (ได้ไฟล์ `.docx` กลับมา)
- **หน้าเว็บ** — `document-automation/power-of-attorney.html` › “เปิดไฟล์งาน / JSON จาก AI” รับ JSON แบบเดียวกับ input ของ MCP

เครื่องมือ **ไม่ร่างหนังสือใหม่** — ใช้แบบของสำนักงานทุกตัวอักษร แล้วพิมพ์เฉพาะส่วนที่เปลี่ยนตามเรื่องลงใน run เดิมของ Word
งานของ AI คือ **เขียนส่วนที่เปลี่ยนให้ถูก สั้น และตรงกับเอกสาร**

## ๑. แบบ (`form`)

| `form` | คืออะไร | ใช้เมื่อ |
|---|---|---|
| `"th"` (ค่าตั้งต้น) | แบบปัจจุบันของสำนักงาน (ก.ย. 2569) ภาษาไทย — ๖ ข้ออำนาจ | ทุกเรื่อง เว้นแต่ผู้ใช้ขอแบบอื่น |
| `"thEn"` | แบบเดียวกัน ไทยตามด้วยอังกฤษทุกย่อหน้า | ผู้มอบเป็นชาวต่างชาติ / บริษัทต่างชาติ หรือผู้ใช้ขอสองภาษา — ต้องส่ง key ที่ลงท้าย `En` ด้วย (เครื่องมือไม่แปล) |
| `"legacy"` | แบบเดิม (2567) — ๘ ข้ออำนาจ ระบุศาล และชื่อเรียกเหตุ | เฉพาะเมื่อผู้ใช้ขอแบบเดิม (ดูข้อ ๖) |

## ๒. แบบปัจจุบัน — ข้อความคงที่ (AI ไม่ต้องเขียนซ้ำ)

```
                                     หนังสือมอบอำนาจ
                              ทำที่ [place — ตั้งต้น: ที่อยู่สำนักงาน]
                      [date]
    โดยหนังสือฉบับนี้ [ผู้มอบอำนาจ] (“ผู้มอบอำนาจ”) ขอมอบอำนาจให้บุคคลที่มีรายนามดังต่อไปนี้
    ┌ ที่ │ รายนามผู้รับมอบอำนาจ │ เลขที่บัตรประจำตัวประชาชน ┐   ← attorneys
    ซึ่งต่อไปในหนังสือฉบับนี้จะเรียกว่า (“ผู้รับมอบอำนาจ”) โดยให้มีอำนาจร่วมกัน และ/หรือ แยกกันกระทำการแทน
    และในนามและเพื่อประโยชน์ของผู้มอบอำนาจ ในการฟ้องร้องดำเนินคดีทั้งทางแพ่งและอาญากับ[counterparty]
    หรือบุคคลอื่นที่มีความเกี่ยวข้อง (“คู่กรณี”) ต่อศาลยุติธรรมที่มีเขตอำนาจ อันเนื่องมาจาก[cause] (“ข้อพิพาท”)
    ตลอดจนดำเนินการทางกฎหมายใด ๆ ที่เกี่ยวข้องกับและจำเป็น ต่อองค์กร หน่วยงานของรัฐ และ/หรือ พนักงานเจ้าหน้าที่…
    ทั้งนี้ ให้ผู้รับมอบอำนาจมีอำนาจรวมถึงแต่ไม่จำกัดเพียงการดำเนินการดังต่อไปนี้ด้วย
      1. ยื่นคำฟ้อง คำร้อง คำคู่ความ แต่งตั้งทนายความ ดำเนินกระบวนพิจารณา จำหน่ายสิทธิ … จนถึงชั้นบังคับคดี
      2. ทำ ลงนาม และรับรองคำแปลภาษาไทย รับรองสำเนา ส่งมอบเอกสาร …
      3. เข้าร่วมการเจรจา ไกล่เกลี่ย ประนีประนอมยอมความ …
      4. ให้การ เป็นพยาน ร้องเรียน … ต่อหน่วยงานรัฐ อัยการ พนักงานสอบสวน พนักงานปกครอง และขอคัดเอกสารทางทะเบียน …
      5. กระทำการในเรื่องใดๆ ที่จำเป็นหรือเหมาะสม …
      6. แต่งตั้งผู้รับมอบอำนาจช่วง …
    การมอบอำนาจตามหนังสือมอบอำนาจฉบับนี้ ให้มีผลตั้งแต่วันที่ที่ลงในหนังสือมอบอำนาจฉบับนี้เป็นต้นไป … ต่อหน้าพยาน …
    [ตารางลงนาม]                    -ติดอากรแสตมป์ [N] บาท-
```

แบบสองภาษา: ย่อหน้าภาษาอังกฤษตามหลังทุกย่อหน้า — “…to institute and conduct both civil and criminal proceedings against
[counterpartyEn], or any other persons concerned (the “Opposing Parties”), before the Courts of Justice having jurisdiction,
arising from [causeEn] (the “Dispute”)…”

**ไม่มี** การระบุศาล ชื่อเรียกเหตุ หรือหน่วยงานในแบบปัจจุบัน — ข้อ ๔ ครอบคลุมการร้องเรียนต่อหน่วยงานรัฐแล้ว

## ๓. สิ่งที่ AI ต้องหามาใส่ (แบบปัจจุบัน)

| key | คืออะไร | วิธีเขียน |
|---|---|---|
| `grantor.type` | `"company"` หรือ `"individual"` | |
| `grantor.company.name` / `nameEn` | ชื่อนิติบุคคลตามหนังสือรับรอง | ไทย “บริษัท … จำกัด” · อังกฤษตามชื่อจดทะเบียน “… Co., Ltd.” |
| `grantor.company.headOfficeAddress` / `…En` | สำนักงานใหญ่ | ตั้งแต่เลขที่ไป (เครื่องมือเติม “สำนักงานใหญ่ตั้งอยู่ เลขที่” / “with its head office at No.”) |
| `grantor.company.directors[]` | กรรมการผู้ลงนาม `{ name, nameEn }` | ตามอำนาจกรรมการในหนังสือรับรอง — ขึ้นเฉพาะในตารางลงนาม |
| `grantor.persons[]` | บุคคลธรรมดา `{ name, nameEn, idType, idNumber, address, addressEn }` | |
| `grantor.capacity` / `capacityEn` | ฐานะ (ถ้ามี) | เช่น “ในฐานะส่วนตัว และในฐานะผู้แทนโดยชอบธรรมของ…” |
| `attorneys[]` | `{ name, nameEn, idNumber }` ตามลำดับในตาราง | เลขบัตร 13 หลัก — ไม่รู้ให้ละไว้ (พิมพ์ “(*)” ไฮไลต์) |
| `matterFacts.counterparty` / `counterpartyEn` | คู่กรณีที่จะฟ้อง | ตามชื่อในเอกสาร หลายรายคั่นด้วย “ และ ” หรือ “ และ/หรือ ” |
| `matterFacts.cause` / `causeEn` | เหตุ ต่อจาก “อันเนื่องมาจาก” / “arising from” | นิติสัมพันธ์ + เอกสาร + วันที่ + สิ่งที่ผิด ไม่มีจุดท้าย |
| `extraClauses[]` | `{ afterClause: 0–6, text, textEn }` | เฉพาะอำนาจที่ ๖ ข้อไม่ครอบคลุม |
| `witnesses[]` | `"ชื่อ"` หรือ `{ name, nameEn }` | `""` = เว้นเส้นให้เขียนเอง |
| `place`, `date` | ทำที่ · วันที่ | ทำที่ละไว้ = ที่อยู่สำนักงาน · วันที่ไม่รู้ให้ละไว้ — **ห้ามเดา** |

**ห้ามแต่งข้อมูล** ชื่อ เลขบัตร วันที่ จำนวนเงิน เลขคดี ที่ไม่มีในเอกสาร — ไม่รู้ให้ใส่ `"(*)"` (พิมพ์ไฮไลต์เหลือง)

## ๕. อากรแสตมป์ — เครื่องมือคำนวณให้

บัญชีอัตราอากรแสตมป์ ลักษณะ ๗ ใบมอบอำนาจ: **(ข)** ผู้รับมอบคนเดียว ๓๐ บาท · **(ค)** หลายคนต่างคนต่างกระทำการได้ **คนละ ๓๐ บาท**
— ถ้อยคำ “ร่วมกัน และ/หรือ แยกกัน” ต้องเสียตาม (ค) (ฎ.7275/2543, ฎ.4932/2549) ปิดไม่ครบ ใช้เป็นพยานหลักฐานไม่ได้ (ม.118)
และผู้รับมอบอำนาจไม่มีอำนาจฟ้องแทน (ฎ.10222/2558)
ผู้มอบหลายคนที่มิได้เป็นผู้มีอำนาจร่วมกัน คิดแยกรายผู้มอบ (ม.108) — ค่าตั้งต้นนับบุคคลธรรมดาแต่ละคนแยกกัน บริษัทนับหนึ่งราย
ถ้าทนายเห็นว่าเป็นผู้มีสิทธิร่วมกันให้ส่ง `stampDuty.principals: 1`

## ๖. แบบเดิม (2567) — `form: "legacy"`

ข้อความคงที่ต่างจากแบบปัจจุบัน: ระบุศาล (`matterFacts.courts`, ขึ้นต้นด้วย “ศาล”), หน่วยงานอื่น (`otherBodies`),
ชื่อเรียกเหตุ (`definedTerm` เช่น “การผิดสัญญา” — ใช้ในข้อ ๑ และข้อ ๖), ทะเบียนนิติบุคคล (`registrationNumber`) และอำนาจกรรมการ
(`authorityWording`) — มีข้ออำนาจ ๘ ข้อ (`afterClause` 0–8) ส่ง key เหล่านี้กับแบบปัจจุบันจะไม่ถูกพิมพ์และได้คำเตือนกลับมา

## ๗. สิ่งที่ต้องบอกผู้ใช้หลังสร้างไฟล์

- แบบที่ใช้ ช่องที่ว่าง (`blankFields`) และเลขบัตรที่ไม่ผ่านหลักตรวจ (`invalidIdNumbers`) รวมถึง `warnings`
- อากรแสตมป์ที่พิมพ์ในเอกสาร และฐานการคำนวณ
- **เป็นร่าง** — ทนายต้องตรวจกับเอกสารจริงก่อนลงนาม

## ๘. ประเภทอื่นของหนังสือมอบอำนาจ (ยังไม่เปิด)

มอบอำนาจช่วง · แจ้งความร้องทุกข์ · ขอเอกสาร/พยานหลักฐาน — ใช้แบบต่างจากฉบับนี้ อย่าใช้เครื่องมือนี้ร่างแทน
